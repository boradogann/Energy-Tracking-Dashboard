# ⚡ Energy Tracking Dashboard

A Streamlit-based web application designed to monitor, visualize, and analyze energy consumption data. 

Currently, the dashboard provides insights based on historical datasets. However, the system is fully designed to support **real-time monitoring**. By integrating the necessary IoT sensors and hardware equipment (such as smart meters or PLCs), the application can easily be scaled to track live active power (kW) and energy usage instantly.

## ✨ Features
* **Data Visualization:** Interactive charts and graphs for tracking energy trends over time.
* **Real-Time Ready:** Architecture is fully adaptable for live data streaming with physical sensor integration.
* **User-Friendly Interface:** Fast, responsive, and easy-to-use web dashboard built with Streamlit.

## 🛠️ Technologies Used
* **Language:** Python
* **Web Framework:** Streamlit
* **Data Handling & Visualization:** Pandas, Plotly / Matplotlib (update if needed)
